# Theory and vocabulary boundary

GCT asks whether final-anchor residual states support reusable empirical transport across controlled
context changes. The organizing picture has contexts, local semantic states, backward restriction,
forward prediction, alternate paths, local matching, and refinement of the contextual base. The v0
experiment does not assume that a transformer literally implements these categorical objects.

The implemented quantities are deliberately named transport defect, cycle-consistency defect,
commuting-square defect, and matching/descent proxy. They are vector-space measurements after a
specified train-fit preprocessing map. They are not Cech cohomology, proof of a sheaf condition,
Beck-Chevalley maps, or holonomy. The implemented pressure/concentration square is a commuting state
update, not a claimed categorical pullback.

Truth labels come only from the Python ToyThermo oracle. A low latent defect can coexist with a wrong
answer, and a coherent model can encode a coherent false world. This is why behavior and the
identical-prompt unobservable control are primary parts of the protocol.

The strongest v0 claim available is conditional: an inferable omitted coordinate is recoverable from
held-out residuals above a grouped permutation null, the identical-prompt unobservable version is not,
explicit exposure improves held-out structure and behavior, irrelevant Q does not, and the result
survives renaming. Even that would be candidate transport structure, not discovery of a universal
ontology.
