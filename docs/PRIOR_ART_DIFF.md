# Prior-art difference

The closest paper located is Adarsh, Maistro, and Lioma (2026), which directly studies geometric
changes in truth vectors after adding context. GCT should not claim that context changes truth-related
residual geometry is new.

The narrower candidate contribution is the conjunction of:

1. an independent, compositional synthetic oracle with nuisance and substantive morphisms;
2. fitted transport operators tested on held-out base worlds and magnitudes;
3. cycle, commuting-square, and matching proxies tied to deterministic transformation metadata;
4. behavior/error association beyond prompt-length and norm controls;
5. residual recovery of an inferable omitted coordinate;
6. explicit base lift compared with matched irrelevant Q;
7. byte-identical unobservable-coordinate pairs that must fail (a rendering check only: their
   residual is zero by construction, so the endpoint has no power against model-side leakage —
   `docs/LIMITATIONS.md`);
8. semantic renaming and frozen-test discipline.

Transformation-equivariant learning, latent flow fields, truth-vector geometry, probes, causal
representation learning, and activation patching each cover important pieces. The search did not
establish that their intersection above is unprecedented, and no universal novelty claim is made.
If the experiment is positive, it is best described as a controlled empirical transport/base-lift
protocol. If negative, it remains a leakage-resistant measurement apparatus and a useful constraint on
linear transport hypotheses.
